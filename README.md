Project Description

The MUST Online Application System is a web-based project designed to provide a simple interface for students applying to the university.

The project contains a login page and an account creation page.

Main Features

- Student login interface.
- New student account registration interface.
- Password confirmation during registration.
- Basic JavaScript form validation and messages.
